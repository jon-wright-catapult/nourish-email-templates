The one thing text-align can't reach: a group whose box still claims its full 50%-of-row width via the mj-column-per-50 class even when it only has one real child inside. That gap is trapped INSIDE the group, not free space at the row level, so text-align has nothing to redistribute. Fix: never build a group with an empty slot.
